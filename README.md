# MasuGate

MasuGate is an open-source research project for stateful governance in concurrent agentic systems.

- [Visit the live website](https://masugate.github.io/)
- [Browse the implementation and research artifact](https://github.com/masugate/masugate)
- [Read “Stateful Governance for Concurrent Agentic Systems” on arXiv](https://arxiv.org/abs/2608.02764)
- [Report a reproducible issue](https://github.com/masugate/masugate/issues)
- [Read the private-reporting policy](https://github.com/masugate/masugate/blob/main/SECURITY.md)

The website explains how MasuGate keeps authorization decisions meaningful when
multiple agents act on shared, changing state. It includes:

- The core challenge of stale authorization and governed execution.
- An interactive OpenClaw scenario that makes the decision lifecycle tangible.
- Evaluation and integration guidance for technical teams.
- Research articles, evidence boundaries, and a way to get in touch.

The implementation and reproducible research artifact can also be
[downloaded as a source archive](https://github.com/masugate/masugate/archive/refs/heads/main.zip).
