# MasuGate

MasuGate is an open-source research project for stateful governance in concurrent agentic systems.

The website explains how MasuGate keeps authorization decisions meaningful when
multiple agents act on shared, changing state. It includes:

- The core challenge of stale authorization and governed execution.
- An interactive OpenClaw scenario that makes the decision lifecycle tangible.
- Evaluation and integration guidance for technical teams.
- Research articles, evidence boundaries, and a way to get in touch.

The implementation and reproducible research artifact are available at
[github.com/masugate/masugate](https://github.com/masugate/masugate).
